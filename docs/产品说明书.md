# Nodpilot · 产品说明书

**产品名称：** Nodpilot  
**版权人：** Min Chen  
**商标：** NODPILOT™（未注册声明，发证前不用 ®）  
**版本：** 1.1  
**适用对象：** 开会、上课、跨语言对话、现场问答时需要当场听懂、事后带走笔记的人  
**运行方式：** 浏览器打开 nodpilot.com，或 iPhone / Apple Watch。无需安装桌面客户端

---

## 1. 产品是什么

Nodpilot 是 **AI Listening Assistant**。承诺三件事：

| | 做什么 |
|---|---|
| **Listen** | 当场听见：实时转写 |
| **Understand** | 当场听懂：翻译、Ask、按场景生成笔记 |
| **Remember** | 事后记住：History 保留 30 天，可搜、回看、导出 |

场景只决定笔记长什么样，不另开一套产品。用户面对的永远是同一场听写：开始听 → 当场理解 → 决定留不留。

顶栏只有两个入口：**Listen** 和 **Translate**。Listen 里再用场景芯片选笔记模板。代码里仍是三个 workspace（`meeting` / `interview` / `translate`），Lecture 是 meeting 的 scene，不要再当成第四个 App。

| 场景 | 何时选 | 笔记 | Save |
|---|---|---|---|
| **Meeting** | 多人讨论、要决策 | Summary · Decisions · Action Items · Follow-ups | Stop / Pause 后提交 History |
| **Lecture** | 一个人讲、要复习（含演示 / 分享） | Overview · Concepts · Examples · Revise · Homework | 与 Meeting 相同 |
| **Live Q&A** | 听见问题，要口头回答 | Summary · Q&A Takeaways | 不弹 Save；问答留在当场 |
| **Translate** | 当场要对着看字幕 | 对照 PDF，不是会议纪要 | 不弹 Save |

**Live Q&A 是现场起草，不是对面试官隐身。** 网页标签会出现在屏幕共享里。不要把生成内容当成官方承诺；请自行核对事实。

麦克风采音，转写走 **AssemblyAI Universal 3.5 Pro**，生成走 **DeepSeek**。网页听不到 Zoom / Teams 系统声。Windows 桌面（系统声、置顶、隐身）是另一条产品，不在这份说明书里。不要启动废弃的桌面 Nod Agent。

## 2. 适合谁、不适合谁

**适合**

- 开会时要决策、待办和事后纪要
- 上课或听分享时要概念和复习笔记
- 跨语言对话时要对着看字幕
- 现场听见问题，需要起草一段口头回答

**不适合**

- 抓取对方电脑扬声器、而不是本机麦克风（网页 / iPhone 做不到）
- 窗口置顶、或对屏幕共享隐藏窗口
- 离线、或不允许音频出网的环境
- 跨所有历史问「上周定价怎么定的」（History 只能搜回这 30 天的场次）

---

## 3. 工作原理（一句话）

```
麦克风 → 16 kHz PCM → Meeting / Lecture 先录完整段、停后再文件转写；Translate / Live Q&A 走 AssemblyAI 流式转写 → DeepSeek 生成 → Listen / Translate 展示
```

Live Q&A 会先判断「这是不是一句完整问题」，再起草回答。Meeting / Lecture 当场只显示录音时钟，停录后一次性出 Transcript 和 Notes。Translate 当场出字幕。

## 4. 开始使用

公测站点用 Google 或邮箱验证码登录。配额在 Account 可见（每日听写约 2 小时）。打开麦克风前会确认同意。

### 4.1 本地还需要的钥匙

云端部署把 Key 配在服务环境变量里即可。本机开发需要：

| Key | 用途 | 获取地址 |
|---|---|---|
| DeepSeek API Key | 笔记 / Ask / 翻译 | [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) |
| AssemblyAI API Key | 语音转写 | [assemblyai.com/app](https://www.assemblyai.com/app) |

读取顺序（后者不覆盖已有值）：环境变量 → Hermes `.env` → 本机 secrets → 页面填写（只存在当前服务进程内存）。

### 4.2 本地打开

见仓库 [README.md](../README.md)。浏览器访问 <http://127.0.0.1:9320>。开发热更新：后端 `9320`，再 `cd web && npm run dev`（Vite `5174`）。

### 4.3 第一场听写（约 1 分钟）

1. 登录后进入工作台。顶栏停在 **Listen**。
2. 场景芯片选 **Meeting** 或 **Lecture**。语言：Speech 是听见什么；Notes 是笔记用什么语言写。
3. 点 **Start**。对着麦克风说话。
4. Meeting / Lecture：点 **Start** 对着麦克风说话。当场只有录音时钟；点 **Stop** 后才出 Transcript 和 Notes。Translate 仍当场出字幕。
5. 可 Ask、可 Summarize（有转写稿之后）。
5. 点 **Stop** 或 **Pause**。弹出 **Save** / **Don't save**。Save 只表示进 History，不导出到 Files。
6. 勾 **Keep recording** 会把这场 WAV 存进账号（默认开，可关掉）。History 打开时会删掉超过 30 天的会话和录音。

## 5. 界面总览

1. **顶栏**：Listen / Translate、账号、History
2. **Listen 场景芯片**：Meeting / Lecture / Live Q&A；Speech 语言；Notes 语言
3. **主按钮**：Start / Stop，听写中有 Pause
4. **主内容**：Live 转写、Notes、Ask
5. **Translate**：From（可 Auto）/ To；Bilingual；More accurate。不走 Meeting 那套 Save 弹窗

听写中途不可切场景。

## 6. 场景说明

### 6.1 Listen · Meeting / Lecture

同一套听写。场景只换笔记模板。

| 按钮 | 作用 |
|---|---|
| **Start** | 开始转写 |
| **Pause** | 暂停采音；Pause 后 Save 仍写同一条，不拆场 |
| **Stop** | 停听，提示 Save |
| **Ask** | 打字问本场（不要和听写抢同一只麦做语音问） |
| **Summarize** | 按当前场景生成笔记 |
| **Save** | 把 draft 标成 kept，进 History。不结束会话，不导出到 Files |
| **Don't save** | 丢掉这份 draft |

### 6.2 Listen · Live Q&A

听见完整问题才起草口头答案。侧栏是问答。不弹 Save。不是隐身小抄。

### 6.3 Translate · 对照字幕

听一句出一句。From 可 Auto，To 锁定目标语。原文已是目标语时标 `Same lang`，不再翻译。Bilingual / More accurate 是显示开关。可 TTS（默认点一下播；Auto 要先确认）。不进 History 那套 Save。

---

## 7. 动词：Save / History / Files

已经定过，不要再混。

| 动词 | 含义 |
|---|---|
| **Save** | 把当前 draft 标成 kept，进账号 History |
| **Don't save** | 丢掉这份 draft |
| **Save to Files** | 只对已经 kept 的会话。拷 PDF / 录音到 iPhone Files 或电脑下载 |

History 可按标题、转写、笔记关键词搜。不能跨会话问 LLM。保留 30 天。

## 8. 端

| 端 | 采音 | 能做什么 | 刻意限制 |
|---|---|---|---|
| Web | 浏览器麦 | 完整 Listen / Translate、Ask、History、账号 | 听不到系统声；标签会出现在屏幕共享里 |
| iPhone | 手机麦，锁屏可续录 | 同一套工作台；Save to Files 走系统文件夹 | Capacitor 套现有网页 |
| Apple Watch | 手表麦（部分模式） | 选模式、Listen / Pause / Done；腕上确认 Save | Meeting / Lecture 仍用手机麦 |

只有当场点 Listen / Record 才切模式并开始。Pause / Resume / Done、残留文件、打开手表，都不得自己开听写。打开手表不得自动播放上一句语音。

---

## 9. 附件与导出

底部 **+** 可附 PDF / Office / 图片 / txt / md（每次最多 5 个，单文件不超过 8 MB）。文本和 PDF 抽正文送给模型。图片不做视觉识别。

Meeting / Lecture 可导出纪要 PDF；Translate 导出对照 PDF。品牌是 Nodpilot。已 Save 的会话才能 Save to Files。

## 10. 部署（给运维）

GitHub + Railway，仓库内 Dockerfile。Volume 挂 `/data`。需要：

- `DEEPSEEK_API_KEY` 或 `OPENROUTER_API_KEY`
- `ASSEMBLYAI_API_KEY`
- `AUTH_SECRET`

容器默认监听 `PORT`（未设则为 8080）。构建时先编译前端 `web/dist`。

## 12. 常见问题

**Q：点了 Start 没反应？**  
先看浏览器是否允许麦克风。`http://127.0.0.1` 一般可用；局域网 IP 的 http 可能被拦。手机 Start 必须出 PCM，否则会报 Microphone is silent。

**Q：Live Q&A 一直转写但不给答案？**  
只对完整问题起草。过短寒暄会丢掉。改用打字 Ask。

**Q：答案语言不对？**  
Speech 和 Notes 是两层。Translate 请改 From / To，不要用 Listen 的语言芯片。

**Q：会议纪要点了没字？**  
需要至少有一行转写。

**Q：翻译停在 Translating…？**  
停听或切语言不应打断无关生成。失败可 Retry。

**Q：能当隐身小抄给屏幕共享吗？**  
不能。网页版不做 Stealth。Live Q&A 是现场起草。

**Q：History 能问上周的会吗？**  
能搜回最近 30 天的场次正文，不能跨会话 Ask。

## 13. 隐私

- 音频发往 AssemblyAI 转写。Save 时若勾 Keep recording，WAV 会存进账号，随 History 保留最多 30 天。
- 转写与附件摘录会发往大模型供应商。
- 请勿在未告知对方的情况下录音；部分司法辖区要求全员同意。
- 用户对自己说出口的内容和是否允许录音负责。
