# Nod 网页版 · 产品说明书

**产品名称：** Nod Web（Nod 网页版）  
**版本：** 1.0  
**适用对象：** 需要实时听题作答、会议纪要或现场口译字幕的个人用户  
**运行方式：** 浏览器打开即可使用，无需安装桌面客户端

---

## 1. 产品是什么

Nod 是一套「听得到 → 转成字 → 立刻给结果」的实时工作台。麦克风采到的声音会送到云端转写，再按当前工作区给出面试回答、会议记录或翻译字幕。

网页版保留桌面版的三个工作区：

| 工作区 | 做什么 |
|---|---|
| **Interview（面试）** | 听面试官提问，流式生成可照着念的回答 |
| **Meeting（会议）** | 实时转写通话内容，标记待办，一键生成纪要并导出 PDF |
| **Translate（翻译）** | 实时字幕：识别一种语言，翻译成你指定的目标语言 |

网页版用浏览器麦克风采音，转写走 **AssemblyAI Universal 3.5 Pro**，回答走 **DeepSeek**（也可接 OpenRouter）。桌面版才有的「窗口置顶」「隐身截屏」「抓系统扬声器」在浏览器里做不到，网页版已去掉这些能力。

---

## 2. 适合谁、不适合谁

**适合**

- 线上面试时，需要把听到的问题立刻变成结构化口头答案
- 开会时需要实时字幕、事后纪要和待办清单
- 跨语言通话时需要中英（及日韩欧语）对照字幕

**不适合**

- 需要抓取对方电脑扬声器、而不是本机麦克风的场景（请用桌面版）
- 需要窗口置顶、或对屏幕共享隐藏窗口的场景（请用桌面版）
- 离线、无 API Key、或不允许音频出网的环境

---

## 3. 工作原理（一句话）

```
浏览器麦克风 → 16 kHz PCM → AssemblyAI 流式转写 → DeepSeek / OpenRouter 流式生成 → 页面展示
```

面试模式下，系统会先判断「这是不是一句完整问题」，过滤语气词、重复句和回声，再生成回答。会议和翻译模式不过滤问题，转写到的句子会直接进入记录或翻译队列。

## 4. 开始使用

### 4.1 需要准备的两把钥匙

首次打开若未配置密钥，会进入 **API Keys** 页，需要：

| Key | 用途 | 获取地址 |
|---|---|---|
| DeepSeek API Key | AI 回答 / 纪要 / 翻译 | [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) |
| AssemblyAI API Key | 语音转写 | [assemblyai.com/app](https://www.assemblyai.com/app) |

两家都提供免费额度。填好后点 **保存并开始**。

**密钥读取顺序（后者不覆盖已有值）：**

1. 服务器环境变量 `DEEPSEEK_API_KEY` / `OPENROUTER_API_KEY` / `ASSEMBLYAI_API_KEY`
2. Hermes 的 `.env`（若本机存在）
3. `%APPDATA%\Nod\secrets.json`
4. 页面里手动填写（只存在当前服务进程内存中，不写入浏览器，也不会发给产品作者）

Railway 等云端部署时，把 Key 配在服务环境变量里即可跳过首次设置页。

### 4.2 本地打开

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
cd web && npm install && npm run build && cd ..
.venv\Scripts\python -m uvicorn server.app:app --host 127.0.0.1 --port 9320
```

浏览器访问：<http://127.0.0.1:9320>

允许麦克风权限后即可说话。开发热更新：后端先起在 `9320`，再 `cd web && npm run dev`（Vite `5174`，会把 `/ws`、`/api` 代理到后端）。

### 4.3 第一次面试（约 1 分钟）

1. 打开页面，确认已过 Keys 页。
2. 顶栏保持 **Interview**。
3. 语言选 **Auto**（中文提问中文答，英文提问英文答）。
4. 点左侧 **Start Listening**，或按 **F3**。
5. 对着麦克风说出面试题，例如：「介绍一下你最近的项目。」
6. 右侧出现问题，下方流式打出回答；按 **C** 可复制最新一条答案。
7. 再按 **F3** 停止监听；**F4** 清空本场记录。

## 5. 界面总览

页面从上到下分为三块：

1. **顶栏**：产品名、三个工作区切换、语言（面试/会议）、麦克风状态、设置菜单（模型、透明度、精简视图）
2. **左侧操作栏**：主按钮（开始/停止）+ 当前工作区专用按钮 + 状态点
3. **主内容区**：随工作区变化（问答 / 转写+纪要 / 双语字幕）
4. **底部输入条**：打字提问、翻译或加备注；左侧 **+** 可附加文件

右下角会短暂弹出状态提示，例如 `Ready · F2 record / F3 listen / F4 clear`。

## 6. 工作区说明

### 6.1 Interview · 面试助手

**用途：** 把面试官的问题转成可直接照着念的口头答案。

**听音方式**

| 操作 | 作用 |
|---|---|
| **Start Listening / F3** | 自动监听：持续听，识别到完整问题后自动作答 |
| **Record / F2** | 手动录音：按一下开始，再按一下结束并作答。最短 0.4 秒，最长 120 秒 |
| 底部输入框 + **Answer** | 不说话，直接打字提问 |

自动监听开启时，手动录音按钮会禁用，避免两路同时采音。

**回答规则（写进模型提示，可在 `config.json` 的 `profile` 里改）**

- 先给结论，再 2–3 点展开；约 60–100 词、3–5 句，便于口头复述
- 行为题用 STAR（情境、任务、行动、结果）
- 技术题：准确结论 + 简短理由
- 语言：Auto 时跟提问语言走；也可强制 CH / EN
- 会带上你配置的目标岗位、公司、简历摘要、JD，以及最近两轮问答作为上下文

**问题过滤（自动监听时）**

系统会丢掉过短的语气词（如 okay、好的）、和上一题高度重复的句子、以及像「回声」一样把上一条答案又听进去的内容。句子像没说完（以逗号、and、or 结尾）会继续等。手动录音和打字提问不做这层过滤。

**精简视图**

设置菜单里的 **Compact view**（桌面快捷键 F8）会收成只显示当前问答的浮层，适合腾出屏幕空间。再按一次或点展开回到完整工作区。

**网页版没有的按钮**

置顶、隐身截屏（Stealth / F9）、系统扬声器开关仅桌面版提供。网页版顶栏麦克风图标只表示「浏览器麦 → 云端转写」，不可切换音源。

### 6.2 Meeting · 会议纪要

**用途：** 把整场会议变成带时间戳的转写，并生成可扫读的纪要。

**操作**

| 按钮 | 作用 |
|---|---|
| **Start Meeting** | 开始转写，计时器启动 |
| **Pause** | 暂停采音，计时保留 |
| **Resume Meeting** | 从暂停处继续 |
| **Stop Meeting** | 结束本场（计时停止） |
| **Mark Action** | 把最新一行标成待办（显示 `Action ·`） |
| **Export PDF** | 导出转写、已标记待办、纪要 |

主区左侧是转写（含 `live` 正在识别的半句），右侧是纪要。底部输入：

- 不填内容直接点 **Generate**：根据当前转写生成纪要
- 填了备注或附了文件再点 **Generate**：按你的说明/附件提问，而不是默认纪要

纪要固定四个板块（模型按此输出）：

- Key points（要点）
- Decisions（决定）
- Action items（待办；只有转写里出现过负责人才会写负责人）
- 不编造人名、数字或承诺

### 6.3 Translate · 实时字幕

**用途：** 听一句、出一句对照翻译。也可打字或贴文件翻译。

**目标语言（To）**

中文、日语、韩语、英语、意大利语、西班牙语、法语、德语、葡萄牙语。源语言自动识别（Auto）。

**听音**

- **F3 / Start Listen**：持续听浏览器麦克风
- **F2 / Record**：录一段自己的话再翻译
- 底部 **Type to translate** + **Translate**：打字翻译

**其它**

- **Bilingual** 开关：开 = 原文 | 译文两列；关 = 只看译文
- 点某一格可复制原文或译文；左侧 **Copy** 复制最新一条译文
- 若原文已经是目标语言，会原样通过并标 `Same lang`，不再浪费一次翻译
- 翻译超时会自动重试最多 2 次；仍失败显示 Failed，可点 **Retry**
- 切换目标语言会取消正在生成的那条，队列里未完成的句子会按新语言重译
- 右下 **…** 菜单：清空（F4）、导出对照 PDF

进入翻译工作区时，识别语言会强制回到 Auto，避免和「源语言自动」冲突。

## 7. 快捷键

焦点在输入框里时，字母快捷键不生效，避免边打字边误触。

| 键 | 面试 | 会议 | 翻译 |
|---|---|---|---|
| **F2** | 手动录音 | — | 录自己的麦克风 |
| **F3** | 开关自动监听 | 开始/停止会议 | 开关持续听写 |
| **F4** | 清空 | 清空 | 清空 |
| **A** | 等同 F3 | 等同 F3 | 等同 F3 |
| **C** | 复制最新答案 | 复制最新一行转写 | 复制最新译文 |
| **X** | 清空 | 清空 | 清空 |
| **F8** | 切换精简视图（面试） | — | — |
| **F9** | 隐身（仅桌面版） | — | — |

精简视图下：

- **C** 复制最新答案
- **/** 或 **Ctrl+K** 唤出输入
- **Esc** 收起输入

## 8. 设置项

点顶栏右侧 **…** 打开。

| 项 | 说明 |
|---|---|
| **Model** | 默认可选 DeepSeek V4 Flash（更快）和 DeepSeek V4 Pro（更稳）。列表来自 `config.json` 的 `models` |
| **Opacity** | 窗口透明度，约 10–100。网页版可调数值，但浏览器标签本身不能像桌面窗口那样半透明叠在其它软件上 |
| **语言 Auto / CH / EN** | 面试、会议：锁定转写与回答语言。Auto 时中英都听，回答跟提问走 |
| **Compact view** | 仅面试：进入精简问答浮层 |

岗位、简历、作答风格不在页面上改，而在仓库根目录 `config.json` 的 `profile`：

```json
{
  "profile": {
    "name": "",
    "target_role": "Software Engineer（软件工程师）",
    "company": "",
    "resume_summary": "",
    "jd": "",
    "style": "简洁结构化：先给结论，再 2-3 点展开；行为题用 STAR 结构；语言口语化、可直接照着念；中文提问用中文答，英文提问用英文答。"
  }
}
```

`stt.vocabulary` 里的词（以及简历/JD 里抽出的英文术语）会作为转写热词，提高专业名词识别率，最多约 50 个。

## 9. 附件

三个工作区底部都有 **+**。

| 规则 | 限制 |
|---|---|
| 类型 | PDF、Word/Excel/PPT（含旧版 .doc 等）、图片（png/jpg/webp/gif/bmp）、txt、md |
| 数量 | 每次最多 5 个 |
| 大小 | 单文件不超过 8 MB |

文本和 PDF 会抽正文送给模型（约前 1.2 万字符）。图片目前按「已附上某图」提示模型，不做视觉识别。Office 二进制以附件名提示，不保证全文解析。

---

## 10. 导出与复制

| 动作 | 面试 | 会议 | 翻译 |
|---|---|---|---|
| 复制 | 最新一条答案 | 最新一行转写 | 最新译文，或点某一格复制原文/译文 |
| PDF | — | 转写 + 已标待办 + 纪要 | 时间戳 + 原文 + 译文对照表 |

网页版导出 PDF 走浏览器打印/下载流程；若取消保存，状态栏会提示 Export cancelled。

## 11. 网页版与桌面版差异

| 能力 | 网页版 | 桌面版 |
|---|---|---|
| 三个工作区、快捷键、附件、导出 | 有 | 有 |
| 麦克风采音 + 云端转写 | 有（仅浏览器麦） | 有 |
| 抓系统扬声器（对方声音不经麦） | 无 | 有 |
| 窗口置顶 | 无 | 有 |
| 隐身（对屏幕共享/截屏隐藏） | 无 | 有 |
| 精简浮层 | 有（面试 Compact view） | 有 |

线上面试若面试官声音从耳机/扬声器出来、而不是进你的麦克风，网页版听不到对方。解决办法：用扬声器外放让麦能收到，或改用桌面版抓系统音频。

## 12. 部署（给运维）

推荐 GitHub + Railway，使用仓库内 Dockerfile。

服务必须配置：

- `DEEPSEEK_API_KEY` 或 `OPENROUTER_API_KEY`
- `ASSEMBLYAI_API_KEY`

容器默认监听 `PORT`（未设则为 8080）。构建时先编译前端 `web/dist`，再由 Python（uvicorn + FastAPI）同时提供静态页、HTTP API 和 WebSocket。

---

## 13. 技术规格

| 项 | 规格 |
|---|---|
| 前端 | React 18 + Vite 6 + TypeScript |
| 后端 | Python 3.12、FastAPI、uvicorn |
| 转写 | AssemblyAI Streaming v3，模型 `universal-3-5-pro`，16 kHz 单声道 PCM |
| 大模型 | DeepSeek（`https://api.deepseek.com`）或 OpenRouter |
| 默认模型 | `deepseek-v4-flash`，温度 0.5；面试默认 max_tokens 约 300–400，纪要至少 1200，翻译至少 800 |
| 实时通道 | 浏览器 WebSocket `/ws` |
| 浏览器音频 | 回声消除、噪声抑制、自动增益；采集后降采样到 16 kHz |

## 14. 常见问题

**Q：点了 Listening 没反应？**  
先看浏览器地址栏是否允许麦克风。Chrome / Edge 对 `http://127.0.0.1` 一般可用；用局域网 IP 的 http 页面可能被拦。状态栏应出现 `Listening for the next question…`。

**Q：一直转写但不生成面试答案？**  
自动监听只对「像问题」的完整句作答。过短寒暄会被丢掉。改用 **F2** 录完整一句，或直接打字点 Answer。

**Q：答案语言不对？**  
顶栏改成 CH 或 EN 强制；Auto 时按识别出的中英比例决定。翻译工作区请改右侧 **To**，不要用顶栏语言钮（翻译页会隐藏该钮）。

**Q：会议纪要点了没字？**  
需要至少有一行转写。空转写时会提示 `No transcript to summarize yet.`

**Q：翻译停在 Translating…？**  
单条超过约 25 秒会重试，最多两次后标 Failed，点 Retry。也可 F4 清空后重来。

**Q：Key 填过还要再填？**  
页面填写只活在当前后端进程内存里。重启服务后若没有环境变量或 `secrets.json`，会再进入 Keys 页。云端请把 Key 放进环境变量。

**Q：会不会把音频或 Key 发给 Nod 作者？**  
不会。音频发往 AssemblyAI，文本发往你配置的 DeepSeek / OpenRouter。页面填写的 Key 只到你自己的服务进程。

**Q：能当隐身小抄给面试官屏幕共享吗？**  
网页版不能。浏览器标签会出现在共享里。需要该能力请用桌面版 Stealth。

## 15. 隐私与合规提示

- 音频会离开本机，发往 AssemblyAI 云端转写。
- 转写文本与附件摘录会发往大模型供应商。
- 请勿在未告知对方的情况下录音；部分司法辖区要求全员同意。
- 面试辅助结果仅供本人准备口头表述，请自行核对事实，不要把生成内容当成官方承诺。

## 16. 状态对照

界面或提示里可能出现：

| 状态 | 含义 |
|---|---|
| Ready | 空闲，可开始 |
| Recording | F2 手动录音中 |
| Listening / In meeting | 持续听写中 |
| Transcribing… | 正在把这段音频转成文字 |
| Checking question… | 面试：判断是否完整问题 |
| Generating answer… / Thinking | 模型正在流式输出 |
| Answer ready | 本轮回答结束 |
| I caught part of a question. Keep listening… | 句子可能没说完，继续听 |
| No speech detected, please try again | 手动录音几乎没声音 |
| Cleared | 已清空本场 |
