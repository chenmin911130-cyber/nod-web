## 1. 顶部 New

- 手机 Listen 页头像左侧增加紧凑 `＋ New`，不另占一行；保留 More 与头像功能。
- New 复用现有 `handleNewSession` 及结束/保存/放弃保护流程，不直接 clear、不绕过匹配的保存确认、不自行改变自动保存规则。
- **最新确认：录音过程中不显示顶部New。暂停仍视为本次录音未结束，也隐藏；Ready/结束后才显示。** Continue恢复录音后再次隐藏。依据capture/会话状态，不因engine生成/Ask回答而短暂出现。此规则覆盖旧图中录音时显示New的示意。
- New可见时沿用现有保存保护规则；取消或保存失败保留原会话，旧回执不得推进新会话。现有More菜单行为不借此改造。

## 2. 录音中：底部单行固定控制栏

- 将本范围内顶部录音控制移到底部，避免重复。单行依次为录音指示、真实音量条、时长、暂停/恢复、结束、Ask气泡图标。
- 目标约60 CSS px高（另加设备安全区），图标触控区域至少44×44；窄屏可收紧装饰，不缩小有效触控区。结束与暂停分隔。
- 暂停切换为恢复；Ended后的 Continue复用当前会话续录：原文/Notes保留、时长累加、数据仍属同一会话。已存在能力做回归，不重写。
- 录音中及暂停保持固定页面和独立正文滚动，无可拖动内容面板/拖动横线。录音前设置不删除；录音中内容优先，结束后仍可访问下一次录音设置，不改变设置含义。

## 3. 轻量动态

- 音量条仅随真实输入幅度变化；静音为低幅静态，暂停/结束停止动画。按钮轻微反馈，尊重 reduced-motion。
- 先确认现有各采集源可用的幅度数据；不得用随机/循环假波形冒充声音，不得为动画重开麦克风、回退原生上行或改音频持久化协议。
- 若某来源无幅度数据，明确显示静态录音状态并在PR列明限制；需要扩展采集协议时回报，不擅自扩大本单。

## 4. Ask收起与键盘

- 常驻输入框改为固定气泡图标，录音时位于底栏内；不支持拖动、不另加重复悬浮按钮。
- 点击展开文字输入并聚焦；提供发送、收起/关闭，草稿在同一会话收起/切标签后保留，新会话不串草稿。
- 提问不停止/暂停采集。沿用现有回答呈现、追问、生成状态、失败重试与内容，不新增聊天数据模型、Thinking、联网、表情或语音输入。
- 键盘打开时从上到下：正文 → 紧凑录音控制 → 输入框 → 系统键盘。正文可视区域缩小仍能滚动，控件不被键盘盖住，不重复加键盘高度/安全区；关闭后恢复布局及合理滚动位置。
- 系统键盘外观由系统决定，示意图省略的emoji/听写键不要求修改或屏蔽系统键盘。
- 已有Quick questions/摘要能力若受收起影响，应在展开区承接，不能因图稿漏画而删除。

## 4A. Translate 底部输入框收起（用户追加授权）

- 仅手机Translate：现有常驻底部输入框默认收起，改成固定的小型Ask入口（对话气泡图标，accessible name为Ask），点击才展开原输入区并聚焦；可收起，保留同一会话草稿及已选附件。
- 这是原输入区的入口/布局调整，**不是把文字翻译改成问答**。沿用`TranslatePane.tsx`现有submit、Type to translate占位语义、附件入口、发送、输出与重试路径；不调用Listen的onAsk、不新增Thinking/联网或新服务端请求类型。
- 输入框/键盘开关不打断正在进行的翻译采集，不重复发送；收起入口不遮挡原文、译文或录音操作。
- 键盘适配现有Translate控制布局，不把Listen的底栏/结束面板/逐句排版整套搬到Translate。保留其语言选择、复制、播放、自动朗读、音色、Retry和所有其他入口。

## 5. 结束后结果面板

- 有内容的结束态才使用可上拉/下拉的结果面板；默认露出结束时长、真实保存状态、Continue和下一次录音设置。顶部New保留。
- 上拉覆盖设置区扩大阅读，保留紧凑结束状态与Continue；下拉恢复。至少默认/展开两个停靠位置。
- 仅拖动把手/标签栏改变面板高度；正文滑动只滚动内容。提供可访问的展开/收起操作，不依赖纯手势。
- 结束态Ask固定在面板右下角，展开后适配键盘；底部留出内容空间。
- 无内容结束沿用Ready；恢复History有内容时不能因ended=false隐藏Ask/内容。恢复历史的续录能力按原有规则，不擅自增加。
- 保存中/失败/Retry/手机持有但未保存History的状态均保留。只在真实确认后显示Saved to History，遵守ADR0002。

## 6. 内容排版（最终确认）

### Transcript
- 每个完整句子一个浅深灰底框，小圆角、紧凑间距，无明显描边/阴影；长句自然换行，不按屏幕行拆框。
- 使用已有稳定文本单元/身份；先核实际MeetingLine结构，不另按句号正则修改服务端断句。多句合并显示需仅在呈现层无损分组，保留原始文本、顺序、说话人、译文、时间信息与复制/导出语义。
- 时间戳用小号灰字，复用实际数据，不编造每句独立时间、不把重复时间戳当断句错误。
- 全局Copy保留，精简重复的Full transcript/All captured speech标题说明；不加每卡操作或新功能。

### Live
- 只给当前正在输出的句子浅底强调，之前内容保持简洁排版；已有说话人、翻译及相关操作仍保留。
- 更新稳定，不反复跳动；用户向上翻阅停止自动跟随，出现新内容时提供回到最新（复用既有滚动逻辑）。

### Notes
- 按现有内容结构使用主题标题、段落、要点；不逐句加框。
- **只改呈现，不改生成内容/提示词，不凭空增删摘要、要点、待办、来源或Ask回答。** 保留Meeting/Lecture原有内容差异及导出/分享等功能。

### 共同视觉
- 黑底、青色强调保留，局部Apple风格：轻分隔、克制底色、统一圆角与间距。正文建议16–17px/约1.5行高、左右约20px，可随窄屏调整。
- 不做全站主题重构，不改变其他页面的导航、颜色或字体。示意文本不写入真实会话。
