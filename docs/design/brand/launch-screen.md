## 缩放到实际屏幕（手机）

启动图（`launch-brand`，851×1847 points）在 storyboard 与覆层里都用**等比适配**
（`scaleAspectFit`）+ 居中。于是：

```
scale = min(bounds.width / 851, bounds.height / 1847)
ox = (bounds.width  - 851 * scale) / 2
oy = (bounds.height - 1847 * scale) / 2
p(x, y) = (x * scale + ox, y * scale + oy)      // 设计坐标 -> 屏幕坐标
```

覆层的标识、字标、波形条都必须用这个映射定位，才能与启动图逐像素对齐。

为什么用 fit 而不是 fill：设计帧比例 851:1847 ≈ 0.461，而 iPhone 从 16:9（0.5625）
到 19.5:9（0.4615）都比它「宽」。fill 会在 16:9 上把整帧放大约 22%，标识变成屏高的
10.6%、波形中心落到屏高 90.8%；fit 则始终保持标识 = 可视高度 8.66%、波形中心 83.4%。
两侧留黑是纯黑底，肉眼不可见。实测：iPhone 15 Pro（393×852）标识 73.89pt = 8.66%；
iPhone SE（375×667）标识 57.75pt = 8.66%。

## 缩放到表盘（watch）

表盘不做 aspect-fill 裁切，改为按可用宽度整体等比缩放并居中：

```
s = min((1 - 2*0.08) * availableWidth / 497.98, (1 - 0.04) * availableHeight / 286.2)
rowCentre = 0.4327 * availableHeight                    // 与设计 cy=799.5 同比例
波形中心   = rowBottom + 0.62 * 160 * s
```

要求：标识与字标之间的 45.72 : 131.282 比例不变；整组水平居中；不裁切、不逐字换行；
波形必须离底部圆角有安全间距（实现里取 12pt 下限，实测 40mm 余 55.1pt、45mm 余 68.0pt）。
40mm（162×197pt）字标 x-height 实测 12.09pt、45mm 14.78pt，均保持可读。
注意表盘比例（0.822）比设计帧（0.461）宽，所以 watch 不做 fit 全套缩放，而是按宽度适配、
再按上面的 rowCentre 定位 —— 表盘的 8.7% 不是目标，可读性与安全间距才是。

## 未纳入的实现细节

- 设计图是 AI 生成的位图，字形有抖动（其标识宽 137 而 logo 真值 131.282，波形条宽
  11.5 而规格 13），所以对**设计图**的像素 IoU 有天花板：标识 ≈0.83、字标 ≈0.74。
  对本仓库自己生成的启动位图（`launch-851x1847.png` / `launch-brand@2x`），原生绘制的
  IoU 为标识 0.973、字标 0.921、波形 0.995 —— 这三者必须一致，才是本单的验收口径。
- 字标按上述度量**几何重建**（圆角矩形字干 + 正圆字腹），不是用系统字体渲染。
- 标识几何直接取自 `web/public/logo.svg` 的两条路径与圆点，仅做等比缩放，未重画。
