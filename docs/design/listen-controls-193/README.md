### 采用的底栏样式

- 保留黑底、青色、现有字体与导航；底栏上缘一条细分隔线，不采用第二张的大号双排按钮。
- Ready：底部约 52–56px 高、横向铺开的青色圆角 Start listening，麦克风图标与文字单行居中，保留安全区。既有录音设置可用。
